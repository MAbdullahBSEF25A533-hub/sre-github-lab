# sre-github-lab

# University Stationary Shop Managment System

## Overview
-Provides ease of access and viewing of the services/ products currently avaiable at the shop
-Prevents rushes and long lines outside the shop by providing services of:-
  1.view products
  2.request print etc

## Scope
- In scope: providing services to people in the university.
- In scope: Recieve orders through an app
- In scope: Send updates for completion and order pick up
- Out of scope: Fee payments.
- Out of scope: supplier management

## Stakeholders
- Student: view stock and request printing documents
- Shop staff : manager inventory, receive orders, send updates
- project maintainer: wants to maintain smooth usage of the app

## Functional requirements
- FR-01: The system shall let a student view available product/servid.
- FR-02: The system shall let a student request a print.
- FR-03: The system shall let staff send updates for completion/unavailability.

## Nonfunctional requirements
- NFR-01: With 100 pending orders, the order list shall appear within
2 seconds in at least 95 of 100 trials on an agreed test device.
- NFR-02: Every task action shall work using a keyboard or phone,
checked against each documented task workflow.

## Acceptance criteria
- FR-01: Send notification "Your order is ready for pick" on 
FR-02: Given more then 10 orders pending, opening the list showing pending orders.
- FR-03: Marking an incomplete task 
displayed status to Complete.

## Assumptions and open questions
- Assumption A-01: internet is available 
- Question Q-01: how many orders do  you deal with daily
- Question Q-02: how do you ensure the order is according to the customer's needs
